This module draws the Mermaid code blocks of HTML fields as diagrams.

A Mermaid block is a code block whose language is ``mermaid``, as
Markdown converters write it: ``<pre><code class="language-mermaid">``,
``<pre class="mermaid">`` or ``<pre class="lang-mermaid">``. The stored
HTML never changes: the diagram is drawn when the field is displayed.

- In read-only fields, the diagram replaces the code block; a **Source**
  button shows and hides the text.
- In the editor, a preview of the diagram is shown below each block and
  follows what you type. It is not saved, not part of the undo history
  and not sent to the other people editing the same document.

The diagrams are drawn in the browser by `Pele <https://pele.run>`__,
shipped with the module and loaded only on pages that show a Mermaid
block. No request leaves the Odoo server.

Use Cases / Context
===================

Documents written in Markdown (specifications, process descriptions,
technical notes) often hold Mermaid diagrams. Once converted to HTML and
stored in an Odoo HTML field, for instance a note or a knowledge page,
the reader only sees the source code of the diagram.

Installation
============

The module has no Python dependency; the Pele library is shipped in
``static/lib/pele``.

Configuration
=============

No configuration is required.

Usage
=====

1. Put a Mermaid block in an HTML field, for instance by pasting
   Markdown with ``web_editor_paste_markdown``, or with any tool that
   writes ``<pre><code class="language-mermaid">`` blocks.
2. Open the record: the diagram is shown below the block while you edit,
   and in place of the block in read-only mode.
3. In read-only mode, click **Source** to see the text of the diagram.

A source with an error shows the error message, with its line and
column, instead of the diagram.

Development
===========

The editor preview is a plugin of the Odoo editor (``editorPlugins`` of
the wysiwyg): previews are inserted with the editor observer off, their
mutation records are filtered out of the history, ``cleanForSave``
removes them from the saved value, and the copy handler removes them
from the clipboard.

To update Pele, replace ``static/lib/pele/pele.global.js`` with the file
of the new npm release and update ``static/lib/pele/README.md`` (version
and checksum).

Known issues / Roadmap
======================

- PDF reports, e-mails, the portal and the chatter still show the source
  of the diagrams: only the backend HTML fields are rendered.
- The sandboxed preview of complex HTML (mass mailing) is not rendered.
- The engine is isolated in ``static/src/js/engine.esm.js``: mermaid.js
  could replace Pele there without changing the rest of the module.
