1. Put a Mermaid block in an HTML field, for instance by pasting Markdown with
   `web_editor_paste_markdown`, or with any tool that writes
   `<pre><code class="language-mermaid">` blocks.
2. Open the record: the diagram is shown below the block while you edit, and in place of
   the block in read-only mode.
3. In read-only mode, click **Source** to see the text of the diagram.

A source with an error shows the error message, with its line and column, instead of the
diagram.
